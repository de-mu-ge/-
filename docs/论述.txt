标题 : 《模型是否以符合人类视觉的方式进行视觉处理？—— LVLM 表征与 EEG 信号之间对应关系的探索》

一. 数据 : THINGS-EEG2 {
    10 名被试   （人数）
    每名被试 82,160 trials  （每个人的测试次数）
    共 16,740(TEST : 200, TRAIN : ) 个 image conditions   （图片条件数） 
    原始 EEG：64-channel    （通道）

    解释 : 一共十个人给他们播放一个影片，每个影（一堆信息，单个脑电信息中有64个通道（采集电极数），
    总共10 * (82160=16740 不定出现) 条数据.图片）片闪过82160个东西（应该包含重复），
    采集每人每影像内容他们的脑电信息，总共16740条脑电

}

二. 逻辑 : LLM与人脑的逻辑存在相似之处

三. 目标 : 查找LLM与人脑的相似处

四. 行为 : 相当于（并不是真的）把同样的操作作用与LLM，通过一些传统算法观察与人类脑电的关系，论文测试了不同的开源模型
（因为需要获取模型推理时内部信息，只能使用可部署模型），观察四个维度{
    （1）预测性能评估；
    （2）预测的时空模式；
    （3）LVLM 层到 EEG的层级时间对齐；
    （4）类别相关的相似性
}
